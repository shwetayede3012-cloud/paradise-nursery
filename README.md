# Paradise Nursery 🌿

Paradise Nursery is a dynamic shopping cart web application built for an online plant shop. Users can browse a variety of houseplants across multiple categories, view detailed product information (image, name, description, and price), add items to their shopping cart, and manage cart contents in real time.

## Features
- Landing page with company introduction and "Get Started" button
- Product listing page with plants grouped into categories
- Add to Cart functionality with dynamic cart icon updates
- Shopping cart page with quantity controls, item removal, and total cost calculation
- Responsive navigation bar across all pages

## Tech Stack
- React.js
- Redux Toolkit (state management)
- CSS

## Project Structure
- `App.jsx` – Landing page
- `AboutUs.jsx` – Company details
- `ProductList.jsx` – Plant categories and product listing
- `CartItem.jsx` – Shopping cart page
- `CartSlice.jsx` – Redux slice for cart state management
